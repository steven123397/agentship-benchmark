# 路线图

## 阶段 0：主分支基础

- 建立 AgentShip 项目说明。
- 固化仓库、分支和 baseline 快照模型。
- 记录评测原则和首个项目方向。

## 阶段 1：首个 Baseline 骨架

- 创建独立的 `baseline/enterprise-rag` orphan branch。
- 按真实项目完成可行性分析、需求分析和第一版设计。
- 确定技术栈、工程结构、基础运行环境和验证入口。
- 建立可继续发展的产品骨架，不加入评测叙事。

## 阶段 2：任务设计

- 选择固定 baseline commit。
- 编写第一条端到端开发任务。
- 定义公开验收标准、隐藏验证和人工评审维度。
- 固定提示词、运行限制和记录格式。

## 阶段 3：试运行

- 将 baseline commit 导出为隔离仓库。
- 使用少量候选 Agent 验证流程是否公平、可复现。
- 修正环境、任务和评分中的歧义。

## 暂不实施

- 自动化批量调度平台
- 公共排行榜
- Web 结果展示站点
- 大规模模型与 Agent 接入
